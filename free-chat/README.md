# 免費工具版：ChatGPT / Claude 網頁聊天

不需 Codex、Claude Code、API Key、程式安裝或付費外掛。只要能使用免費聊天功能，將 `PROMPT.md` 的全文貼進聊天，再附上考卷（若無法上傳 PDF，可貼文字或分批提供題目截圖；受各平台免費額度限制）。

**這不是能直接安裝的 Agent Skill。** AI 只負責分析與產出題號、配分、公式和人工操作清單；使用者親自登入 Google Sheets 完成複製分頁、欄位插入、核取方塊與公式貼上。不得宣稱 AI 已操作試算表。

## 每週操作
1. 在 Google Sheets 找最新一次**正式日期**分頁（不要用 `test` 或樣板），右鍵「複製」建立新分頁；如此保留最新學生名單與格式。命名為當週六 `MMDD`。
2. 開啟 ChatGPT Free 或 Claude Free，貼上 `PROMPT.md` 全文，提供本週考卷與配分、選擇題規則；若有不明處先回答 AI 的確認問題。
3. 把 AI 回傳的題目欄位配置、公式與檢查表用於**新分頁**。新增題目欄應在右側分隔欄前插入；從現有核取方塊欄複製格式與資料驗證。
4. A 欄學生列按「Delete」清除**值**（不要清除格式或資料驗證）；B 欄和題目核取方塊全部取消勾選；C 欄保留學生名單。
5. 複製公式到每位學生的成績、錯題數、正確題數欄；修改統計區塊的範圍至最後學生列，並確認不包含統計列。
6. 先在 `test` 或測試分頁檢查滿分、錯題數、核取方塊、下拉選單及顏色，再處理正式資料。

## 免費版限制
- 免費聊天產品的上傳、長度、執行能力與額度可能變動。
- AI 沒有直接修改 Google Sheets 的權限；所有改動由使用者執行。
- 不上傳包含學生姓名與成績的完整表格到公共服務；能用匿名範例就使用匿名範例。
