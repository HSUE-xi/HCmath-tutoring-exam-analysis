# HCmath 小考分析｜雙版本

| 版本 | 路徑 | 適用工具 | Google Sheets 寫入 |
|---|---|---|---|
| 免費工具版 | `free-chat/` | 免費 ChatGPT / Claude 網頁聊天 | 使用者手動操作 |
| Agent Skill 版 | `agent-skill/` | Codex / Claude Code | 設定並授權連接工具後可自動化 |

兩版的共通規則：最新正式日期分頁 C 欄為學生名單來源、A 清值保留下拉選單、B 與題目核取方塊重設 FALSE、多選題逐選項判錯、配分不明先問、不能改歷史分頁或樣板。

- 免費版：閱讀 `free-chat/README.md`，將 `free-chat/PROMPT.md` 貼進聊天。
- 進階版：閱讀 `agent-skill/README.md`，安裝含 `SKILL.md` 的整個資料夾。

**安全：** Repository 請設為 Private，僅邀請有工作需要的同事；不要提交真實學生資料、成績、考卷答案、Google 憑證或 token。即使是 Private Repo，存取 Google Sheets 仍需個別授權。
